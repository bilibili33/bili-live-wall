B 站直播监控墙 —— 免安装版
========================================

怎么用
  1. 把整个 bili-live-wall 文件夹解压到任意位置。
     （别只把 exe 单独拖出来，_internal 是它的运行库，缺了打不开）
  2. 双击 bili-live-wall.exe
  3. 浏览器会自动打开监控画面。没自动打开就手动访问 http://127.0.0.1:8848/

两个地址
  监控画面   http://127.0.0.1:8848/
  配置后台   http://127.0.0.1:8848/admin
             ↑ 在这里加/删直播间、改宫格行列、调刷新间隔、改日志级别

怎么关
  在那个黑色控制台窗口里按 Ctrl+C，或者直接关掉窗口。


出问题了怎么办（重点看这段）
----------------------------------------

控制台现在会把每一步都打出来。如果画面就是拉不到，按顺序做这两件事：

  1) 跑一次自检。在文件夹里按住 Shift 右键 →「在此处打开 PowerShell/终端」，然后：

         .\bili-live-wall.exe --selftest

     它会把 DNS、TCP、TLS 证书、B 站接口、图片 CDN、写盘全测一遍，
     并把报告存成 data\selftest-日期时间.txt，把那个文件发出来即可。

  2) 看日志文件：data\bili-live-wall.log
     里面记着每一次 HTTP 请求的结果和每个房间的截图结果。

常见的几种情况：

  * 只有状态、没有画面（拉不到关键帧）
      B 站接口和图片 CDN 用的根证书不是同一套：
         api.live.bilibili.com  → GlobalSign R3
         i0/i1/i2.hdslb.com     → GlobalSign R46
      如果这台机器的系统根证书库偏旧（关过 Windows Update、LTSC 版、长期离线），
      就会出现「状态能拉到、图一张都拉不到」。
      本程序内置了一份 CA 包，和系统库并集使用，正常情况已经不受影响；
      自检里会明确告诉你系统库认不认得出这些域名。

  * 网络本身不通
      自检会显示 DNS 解析失败 / 连接超时 / 证书被替换。
      可以试试点「配置后台 → 参数设置 → 测试接口连通性」，
      或者把 DNS 换成 223.5.5.5、119.29.29.29 再看看。

  * Windows 弹出“已保护你的电脑”
      因为这个 exe 没有买代码签名证书。点“更多信息”→“仍要运行”。

  * 杀毒软件报毒
      PyInstaller 打包程序的通病（bootloader 特征），加白名单即可。
      源码完全公开，可以自己核对或自己打包：
      https://github.com/bilibili33/bili-live-wall

  * 端口 8848 被占用
      改 config.json 里的 server.port，或者启动时加参数：
      .\bili-live-wall.exe --port 9000

  * 想看更啰嗦/更安静的日志
      .\bili-live-wall.exe --log-level debug
      （也可以在配置后台把「控制台日志级别」改成 info / warn / error）


首次运行会在这个文件夹里生成
  config.json   你的全部设置（含直播间列表）。删掉就会重新生成默认的四间。
  data\         截图、状态缓存和日志。随便删。
    shots\              每个房间当前的画面截图
    bili-live-wall.log  运行日志（超过 5MB 自动轮转一次）
    selftest-*.txt      自检报告


画面怎么看
  * 直播中的窗口：显示当前画面截图、直播标题、主播名、人气，带粉色描边；
    左上 CHxx 是通道号，右下是这张截图的时间。
  * 没在播的窗口：铺那张“房间暂未开播”的底图，左下角显示主播名。
  * 双击页面 = 全屏，再双击或按 Esc 退出。

关于画面刷新速度
  B 站的关键帧图本身大约 10 秒 ~ 4 分钟才换一张，所以这是
  “每隔一会儿更新的截图墙”，不是视频流。想更实时只能上无头浏览器，
  那种方案每个房间要起一个 Chrome 进程，重得多。
